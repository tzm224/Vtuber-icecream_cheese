# 验证记录与 Mac 实机清单

## 当前验证边界

本项目初始开发环境为 Linux，没有 macOS AppKit 运行环境或 Swift 编译器。

- 本地可验证：安装器的隔离模拟测试、Shell 语法、PNG 像素与 manifest 的一致性、配置格式。
- GitHub macOS CI 验证：Swift 编译与单元测试、Apple Silicon / Intel 双架构构建、签名完整性、打包后的进程启动存活。
- 尚需人工 Mac 验证：真实桌面的拖拽、透明区域穿透、多屏、Space、全屏应用、休眠唤醒与视觉表现。CI 不能替代这些测试。

不要把 Linux 测试通过或 CI 进程启动理解为整套交互已通过实机验收。

## Mac 验收清单

1. 在 macOS 13+ 的 Apple Silicon Mac 与 Intel Mac 分别安装，确认不用 Xcode/Homebrew。
2. 首次运行可见完整角色、透明背景、合理大小、没有窗口边框或黑底。
3. 单击挥手、双击跳跃、右键菜单、菜单栏退出均正常；连续快速点击不崩溃。
4. 拖拽到另一屏幕、屏幕边缘、Dock 附近，再释放；角色不会永久丢失。
5. 透明背景点击穿透，角色轮廓处可点击。拖拽经过透明区时不会中途丢失捕获。
6. 16 方向视线正确，鼠标不动后恢复待机；关闭视线跟随后保持自然待机。
7. 散步左右方向正确，不超出可见屏幕；关掉散步、暂停、恢复均可重复使用。
8. 打开菜单再取消，拖拽再点击，重复隐藏/显示和调整大小，不出现卡住或状态残留。
9. 不抢输入焦点；切换 Space、进入/退出全屏、屏幕睡眠和系统休眠后仍可操作。
10. 显示器移除或分辨率变化后角色留在有效区域。退出重开恢复位置与偏好。
11. 应用运行时再启动不会产生第二只；关闭后可正常重启。
12. 下载中断、校验失败、应用运行时更新均安全退出；旧版更新有备份，卸载进废纸篓。
13. macOS 安全阻止时只走系统提供的允许打开流程，绝不要求关闭 Gatekeeper/SIP。
14. 活动监视器中确认 CPU/内存合理，工作时不持续产生网络连接。

## 自动检查

```bash
python3 -m unittest discover -s tests -v
python3 scripts/validate_assets.py
bash -n install.sh scripts/*.sh
swift test # macOS / Swift 环境
bash scripts/build.sh # macOS
```

安装器测试将 macOS 命令替换为隔离 stub。覆盖两种 CPU、首次安装、更新备份、旧应用保护、符号链接、校验失败、危险压缩包路径、签名/标识错误、下载失败清理、系统版本限制和启动失败。它不会安装应用到测试者的真实 HOME。
