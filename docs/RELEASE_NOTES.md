雪糕cheese 非官方 Mac 桌宠，支持 macOS 13+ / Apple Silicon / Intel。

- 原生透明置顶窗口，拖拽、点击互动和菜单栏控制。
- 9 组动作、57 动画帧与 16 个视线方向。
- 高清重绘风格与 2× Retina 资源，桌宠显示大小保持不变。
- 自动散步、鼠标视线跟随、三档大小、暂停与隐藏。
- 本地运行，无账号、遥测、录音或数据上传。
- 安装器验证 SHA-256 和应用完整性，不需要 sudo、Homebrew 或 Xcode。

安装说明见仓库 README。下载文件：CheesePet-macOS-universal.zip 与 SHA256SUMS。
